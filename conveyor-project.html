Colour Sorting Conveyor Belt

Arduino Nano · TCS230 Colour Sensor · MG996R Servo · L298N Motor Driver · 12V DC Motor · C++ · Electronics · Automation

Project Overview

I built a colour-sorting conveyor belt system to learn more about electronics and controls through microcontrollers. The idea came from my time working at a meat processing factory where I saw industrial sorting systems in action — I wanted to understand how they actually worked by building a scaled-down version myself.

See It in Action

System Logic

Once the code is uploaded to the Arduino Nano, a "System initialized" signal prints to the serial monitor. Mounted above the conveyor is a TCS230 colour sensor programmed to identify blue and red objects while ignoring everything else.

When a blue object is detected, the microcontroller initiates a 3.5-second transit delay to let the object reach the sorting terminal. The MG996R servo arm then deploys at a 70° angle, creating a physical barrier. The object's own momentum — guided by the stationary arm — diverts it off the belt. A 0.5-second clearing phase follows before the system resets.

When a red object is detected, the belt runs for 11.5 seconds until the object reaches the end and falls off naturally.

Problems & Solutions

Consistent Colour Detection

The sensor struggled to read colours reliably while the belt was moving. The fix was to pause the belt during detection and only execute commands once the sensor was confident in its reading. A separate testing programme was written first to map the exact data range each colour produced.

Belt Traction

Getting the belt to move smoothly without slipping was harder than expected. Cardboard and bare wood rollers didn't provide enough grip. The solution was wrapping the wooden rollers in elastic exercise band material, which gave consistent traction.

Do Differently

  • Use actual measurements when building the frame — rough estimates caused alignment issues
  • Make the belt longer to fit a second colour-sorting terminal
  • Potentially add a HMI display in a future version
